# 🎬 Webflyx — SQL Database Project

A fictional streaming platform database built as part of the [Boot.dev](https://boot.dev) Back-end Developer Path.  
This project applies core SQL skills to a real-world-style schema: a content catalogue modelled on a streaming service.

---

## 📌 What This Project Covers

- Designing and querying relational database tables
- Working with CSV data imports (`classics.csv`)
- Writing structured content and title documentation in Markdown
- Organising quote/reference data across a multi-file project structure
- Practising SQL fundamentals: SELECT, JOIN, INSERT, filtering, aggregation

---

## 🗂️ Project Structure

```
webflyx/
├── classics.csv       # Dataset of classic titles used for import and querying
├── contents.md        # Catalogue overview — content types and structure
├── titles.md          # Title listing and metadata reference
└── quotes/            # Supporting reference data
```
